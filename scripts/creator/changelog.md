# 创建器版本记录

## 0.3.0-rc.3

三个模板都包含本次收件箱修复，刷新时保留已确认的已读状态，分页详情会重新读取正文。山岚步道内置独立模块 0.1.2。候选附件附上两批 0.1.1 和首个候选版的原始模块包，可按来源提交复核升级。

## 0.3.0-rc.2

三个模板更新构建工具的间接依赖和锁文件。H5 开发服务默认绑定本机回环地址，关闭 Vite 的 CORS 响应头并启用 Vite 工作区文件访问限制。青禾书房继续通过同源 `/api` 接入示例服务。

## 0.3.0-rc.1

提供 basic、reading-room、embedded 三种模板。山岚步道示例复用宿主登录和原生底栏，可用下载的独立模块包验证首次安装与跨版本升级。basic 的移动端验收覆盖长消息列表滚动恢复和取消返回后继续输入中文。
