# 移动端验收

使用生成项目的生产包和示例账号。basic 用于复测昵称、登录和消息列表。reading-room 用于复测从分享链接启动及换号。embedded 用于复测返回原生底栏与宿主业务页。

## H5 自动验收

在生成的项目根目录运行以下命令。CI 也通过 `check:h5` 运行对应示例的验收。

```sh
npm ci
npm run build:h5
npx playwright-core install --only-shell chromium
npm run check:h5
```

basic 先在 390 × 844 检查原有账户流程，再使用独立的触屏浏览器会话，将视口设为 **320 × 568 CSS 像素**、Chromium 最小字号设为 **24 像素**。缩短视口模拟键盘占位。操作前会滚动到控件，确认它的中心位于可视区且未被其他元素遮挡，再发送触屏点击。

| 操作 | 通过条件 |
| --- | --- |
| 打开 basic，查看底栏「消息」上的未读角标 | 在 24 像素最小字号下，数字完整落在角标背景内，角标也完整落在可点按的消息按钮内 |
| 在「我的 → 编辑资料」输入 20 个字符（青禾、17 个大写 W、舟）。输入框聚焦时把可视高度从 568 缩至 308 像素 | 输入框保持焦点且完整可见。按浏览器返回触发未保存提示，点「取消」后，昵称与表单滚动位置保留 |
| 在 308 像素高的视口滚动并点「保存资料」 | 回到「我的」。长昵称完整换行，每行都在卡片内，页面没有横向滚动。刷新仍显示保存后的值 |
| 打开「消息」，点「加载更多」，滚动到「账号安全检查」并记下位置。进入详情后用页内返回键退出 | 同一消息行仍在原位置。自动断言行顶和容器滚动量各自偏差不超过 2 CSS 像素。第二页仍在，消息已读，未读角标从 2 变为 1 |
| 退出再登录，聚焦密码框后再次缩短视口，输入演示密码并点「登录」 | 能看到正在输入的字段，登录按钮可滚动到并点中。返回「我的」时仍是此前保存的昵称 |
| 用 reading-room 分享借阅详情，在新的 320 × 568 会话打开链接，登录，再点「返回列表」 | 回到分享的同一条借阅记录。可回到当前读者的列表，换号后看不到上一位读者的记录 |

## 微信开发者工具

在生成项目运行 `npm run build:mp-weixin`，导入 `dist/build/mp-weixin`。basic 的首次安装有两条未读消息。复测时使用独立的示例环境，以免已有已读状态影响角标判断。选择窄屏机型或自定义 320 × 568 逻辑像素。用「我的 → 编辑资料」复测输入、取消离开、保存与重新打开。用「消息 → 加载更多」复测消息详情返回。记录机型的逻辑宽度与字号档位，预览缩放百分比只代表画面在电脑上的显示大小。

本轮在微信开发者工具的 iPhone 12/13 Pro 模拟器（逻辑宽度 390 像素）验证了 basic。编辑昵称后点返回，取消离开可继续保存，回到「我的」可见完整换行的昵称。进入「账号安全检查」再返回，原行变为已读，角标由 2 变为 1，加载过的第二页仍在。该机型下消息列表可整页显示。非零滚动位置的精确对照已在 320 像素 H5 完成，微信端需在能实际滚动的设备上复测。

## 真机待核对

记录机型、系统与微信版本、宿主（浏览器、微信内 H5 或小程序）、字号档位和输入法。每次进详情前记录可见行及其距顶部的位置，回到列表后在滚动前对照。若列表尚未产生滚动，先加载下一页或选择更窄的设备。

| 场景 | 实机操作与通过条件 |
| --- | --- |
| 大字号和窄屏 | 分别在 iOS、Android 的系统大字号及微信大字号下打开 basic。输入上面的混合昵称。检查每行文字、未读角标、底栏和保存按钮都完整。可纵向滚动触达主操作，页面无横向拖动 |
| 真实软键盘 | 在 Safari、Android 浏览器、微信内 H5 和小程序中分别聚焦昵称、密码。切换中文输入法，展开候选栏，提交前确认组合文字已经上屏。焦点、光标和当前输入内容可见，键盘展开时能滚动并点击保存或登录。键盘收起后底部没有空白占位，底栏可点 |
| 未保存与系统返回 | iOS 测侧滑，Android 测返回手势或系统返回键。先记录键盘是否仅被收起。可离开且有草稿时出现一次确认，取消后文字和编辑位置保留，选择放弃则旧昵称保持原值。小程序资料页设置了 `disableSwipeBack`，侧滑被禁用时应仍停在原页，再用页内返回复测 |
| 列表返回与宿主导航 | 在 basic 点开已滚动列表中的消息，用系统返回和页内返回分别复测。已读和角标同步，只退一页，分页和原行位置保留。embedded 从路线详情打开集合通知，登录或取消后按返回，核对路线详情和原生底栏 |
| 冷启动分享 | 在 reading-room 分享《山川笔记》详情。退出小程序后从会话卡片打开。相同读者登录后回原记录，返回列表只显示该读者的书。换号无权查看时能回本人的列表。手机需能访问示例 API，具体账号与接口配置见该示例的 README |
| 读屏操作 | 用 VoiceOver 和 TalkBack 聚焦「编辑资料」「保存资料」及返回按钮。朗读可区分操作，双击生效，关闭离开确认后能继续编辑 |

通过记录应区分浏览器自动验收、开发者工具和实机。桌面缩短视口能检查焦点、布局与触点。输入法候选栏、系统字体放大、原生键盘与系统返回手势需记录实机结果。
